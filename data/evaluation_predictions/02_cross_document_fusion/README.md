# 跨文档消融

页面：`/evaluation/cross-document/fusion`

1. 选择“上传抽取结果 JSON”模式，并上传本目录 `predictions.json`。
2. “真实结果标注 JSON”处上传本目录 `gold.json`。
3. 展开“公开运行配置”，上传本目录 `options.json`。
4. 点击“使用已有结果计算指标”。无需上传文本。

共 12 篇文档。预测数据来自历史真实算法结果，没有从人工答案生成预测。已通过当前上传解析和纯评分流程复验，与原报告指标完全一致。专业领域包含实际基线预测，融合和社区包含实际预测分组，时空包含标准化预测值。完整来源、文件哈希和复验指标见 `verification.json`。

## 配套原始文本

`texts/` 包含本模块全部 12 篇原始 TXT，与预测及 gold 的文档 ID、文件名、语言一一对应。文本字节与历史评测输入哈希一致，正文内容也与保存的算法输入逐篇核验。对应关系与逐文件 SHA-256 见 `text_alignment.json`。

若要从文本重新预测，选择“上传文本，实时抽取”，上传 `texts/` 中全部 TXT，再上传同目录 `gold.json` 和 `options.json`。若使用已有预测直接评分，则只上传预测、真实标注和配置。重新调用模型的结果可能波动，现有预测文件保留的是历史实际输出。
